# CardioSense — An AI-Powered Heart Sound (PCG) Anomaly Detection and Screening System

> **Abstract** : CardioSense is an AI-powered system for detecting anomalies in heart sound recordings, designed as a research and educational screening tool. The system captures phonocardiogram (PCG) audio via a smartphone microphone, applies digital signal processing techniques (bandpass filtering, noise reduction, and segmentation) to isolate the S1/S2 heart sound cycle, and converts the cleaned audio into mel-spectrogram representations. A Convolutional Neural Network (CNN), trained on the public PhysioNet/CinC Challenge 2016 heart sound dataset, classifies each recording as normal or abnormal with an associated confidence score.

The system is built as a full-stack application: a React frontend handles audio recording and result visualization via the Web Audio API, while a FastAPI backend manages preprocessing, model inference, and result storage. The project demonstrates practical application of signal processing, deep learning, and full-stack engineering to a real-world biomedical use case, while maintaining clear framing as a screening aid rather than a diagnostic device.

Key learning outcomes include audio signal processing, CNN-based classification, handling noisy real-world biosignal data, and building an end-to-end deployable AI application.
